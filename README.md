# Multi-lingual Sheet Music Generator

The app matches the English lyrics in the musical score against the English lines in the annotated layout PDF. It then transfers the translation attached to each matched English line into the original score positions.

## macOS

Open Terminal, type `cd `, drag the extracted `multilingual_sheet_music_generator` folder into Terminal, press Return, then run:

```bash
chmod +x run_mac.sh
./run_mac.sh
```

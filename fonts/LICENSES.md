# Bundled fonts

- **LiberationSerif-Regular.ttf**, **LiberationSerif-Italic.ttf** — Liberation Fonts,
  SIL Open Font License 1.1. Metric-compatible with Times New Roman, which is what most
  engravers use for lyrics.
- **DejaVuSans.ttf** — DejaVu Fonts, free licence (Bitstream Vera derivative).

Both cover the accented and modifier letters used by languages such as Aymara.
